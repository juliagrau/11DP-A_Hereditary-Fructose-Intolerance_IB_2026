## Description
Bioinformatics course project analyzing Hereditary Fructose Intolerance (HFI). Compares wild-type vs. mutant CDS/protein sequences and studies non-human homologs, including Oryctolagus cuniculus. Developed for Introduction to Bioinformatics, Group 11DP-A (UPC).
